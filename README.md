# Calculadora Interativa em C

![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)
![Language: C](https://img.shields.io/badge/Language-C-blue.svg)

Uma aplicação simples e eficiente de calculadora executada via linha de comando (CLI), desenvolvida em Linguagem C. O projeto permite realizar operações aritméticas básicas de forma interativa diretamente no terminal.

## 🛠️ Pré-requisitos e Instalação

### Pré-requisitos

Para compilar e executar este projeto, você precisa de um compilador C instalado no seu sistema (como **GCC** ou **Clang**).

#### Como verificar a instalação:
```bash
gcc --version
