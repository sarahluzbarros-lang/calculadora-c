# Calculadora Interativa em C

![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)
![Language: C](https://img.shields.io/badge/Language-C-blue.svg)

Uma aplicação simples e eficiente de calculadora executada via linha de comando (CLI), desenvolvida em Linguagem C. O projeto permite realizar as operações aritméticas básicas de forma interativa diretamente no terminal.

## 🛠️ Instalação e Pré-requisitos

### Pré-requisitos

Para compilar e executar o código em C, é necessário ter um compilador C instalado no seu sistema operacional, como o **GCC** (GNU Compiler Collection).

#### Como verificar a instalação do GCC:
Abra o terminal e execute:
```bash
gcc --version
